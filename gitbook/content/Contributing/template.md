## [Sectie 2: uitwerking / code]

Elk codevoorbeeld staat in een fenced codeblok met een taal-tag en, waar nuttig, de
bestandsnaam erboven. Bijvoorbeeld:

```ts
// voorbeeld.ts
export function hello(name: string): string {
  return `Hello ${name}`
}
```
